- **On TestFlight** — The iOS app is available through TestFlight. Sign-up uses an email address and password with a verification step, and invite links open straight into the app.
- **Onboarding by role** — A parent can start a pod or join one with a code, add children, and describe the home they host from. A nanny answers eligibility, photo, bio, age-range, rate, and pay-frequency questions.
- **The schedule** — Create a session at a host home, set which children attend and for which hours, see the capacity effect before confirming, cancel, and invite a nanny to a specific session.
- **Today tab** — One list of the day's sessions.
- **Hosting locations** — Add a home with address autocomplete from the profile screen, then mark it complete.
