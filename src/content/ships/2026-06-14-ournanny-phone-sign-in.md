- **Sign in by phone** — Enter your number, type the code from the text, and you are in. No passwords.
- **Invites by text** — An admin enters a name and a number and gets an invite code plus a ready-to-send text. The invitee's account connects to that invite when they sign up with the same number.
- **New login screens** — The sign-in screens were redesigned around a single logo on a warm ivory background.
