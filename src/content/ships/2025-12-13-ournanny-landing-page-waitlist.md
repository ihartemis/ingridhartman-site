- OurNanny got a public front door at ournanny.app. The page pitched the product to families already running a nanny share, under the line "Nanny share, without the spreadsheet."
- Every call to action opened a Typeform waitlist. The copy described a free beta planned for early 2026 covering scheduling, host locations, attendance tracking, and automatic cost reporting.
- The page was a single static file with a desktop menu and a hamburger menu below 992px, so it read cleanly on a phone, which is where most parents would first see it.
- Follow-up commits the same week rebuilt the footer, narrowed the app screenshot cards so they fit on mobile, and added links to the OurNanny accounts on X and Instagram.
